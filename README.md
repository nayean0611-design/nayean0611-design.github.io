# 포트폴리오 템플릿

HTML, CSS, JavaScript로만 만든 1페이지 포트폴리오 템플릿입니다. 별도 빌드 과정 없이 GitHub Pages에 바로 올려서 쓸 수 있습니다.

## 폴더 구조

```
portfolio-template/
├── README.md                    # 템플릿 사용 설명서
├── prompts.md                   # 내용 채우기용 프롬프트 템플릿 모음
├── index.html                   # 페이지 본문 ({{ }} 부분을 내 내용으로 채우는 파일)
├── style.css                    # 전체 스타일 (:root 색상 값으로 톤 조정)
├── script.js                    # 메뉴, 스크롤 등 동작 처리
└── images/                      # 프로필 사진, 프로젝트 스크린샷
    ├── 헬로빗.png                # About Me 프로필 이미지 (예시)
    ├── project-example.png      # 프로젝트 카드 1 썸네일 (예시)
    ├── project-example-2.png    # 프로젝트 카드 2 썸네일 (예시)
    └── project-example-3.png    # 프로젝트 카드 3 썸네일 (예시)
```

## 파일 구성

- `index.html` : 페이지 본문. `{{ }}`로 표시된 부분을 본인 내용으로 채우면 됩니다.
- `style.css` : 전체 스타일. `:root`에 정의된 색상 값만 바꿔도 전체 톤이 바뀝니다.
- `script.js` : 메뉴, 스크롤 효과 등 동작 처리.
- `images/` : 프로필 사진, 프로젝트 스크린샷 등 이미지 파일.

## 구성 섹션

1. Hero : 이름과 한 줄 소개
2. About Me : 관심 분야, 진행 중인 일, 학습 중인 기술 등 4가지 항목
3. Tech Stack : 주로 쓰는 기술과 학습 중인 기술을 태그로 표시
4. Projects : 프로젝트 카드. 썸네일, 역할, 설명, 주요 기능, 트러블슈팅, 성과, 기술 태그, 링크로 구성
5. Activities : 수상, 동아리, 대외활동 등을 시간순으로 정리
6. Contact : 이메일, GitHub, 블로그 등 연락 링크

필요 없는 섹션은 `<section>` 태그째로 지우고 상단 메뉴에서 해당 링크도 함께 지우면 됩니다.

## 기본 기능

- 반응형 레이아웃. 화면이 좁아지면 상단 메뉴가 햄버거 버튼으로 바뀝니다.
- 스크롤 위치에 따라 현재 보고 있는 섹션 메뉴가 자동으로 강조됩니다.
- 섹션이 화면에 들어올 때 서서히 나타나는 스크롤 등장 효과.
- 화면을 내리면 나타나는 맨 위로 이동 버튼.
- 푸터의 연도는 자동으로 올해 연도로 표시됩니다.
- 프로젝트 카드에 이미지를 넣으면 정해진 비율로 잘려서 보이고, 이미지가 없으면 해당 부분만 지워도 레이아웃이 깨지지 않습니다.
- 애니메이션을 줄이도록 설정한 사용자에게는 등장 효과와 부드러운 스크롤이 자동으로 꺼집니다.

## 사용 방법

1. `index.html`에서 `{{ }}` 부분을 실제 내용으로 채웁니다.
2. 프로필 사진, 프로젝트 스크린샷을 `images/` 폴더에 넣고 경로를 연결합니다.
3. 브라우저로 `index.html`을 열어 확인합니다.
4. 저장소 이름을 `깃허브아이디.github.io`로 만들거나, 저장소 설정에서 GitHub Pages를 켜서 배포합니다.

## 주의할 점

- 파일 이름은 반드시 `index.html`로 유지해야 GitHub Pages가 인식합니다.
- 전화번호, 집 주소, 학번 같은 개인정보는 넣지 않습니다.
